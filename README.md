Official website for **IB Premium Art** – a construction company based in Skopje, North Macedonia, specializing in:

- **Knauf, Rigips & Tehnogips** dry construction systems
- **Armstrong** suspended ceilings
- **Hunter Douglas** premium architectural ceilings
- Painting, plastering & whitewashing

## 🚀 Deployment to GitHub Pages

1. Push all files to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to **main** branch, root folder `/`
4. Your site will be live at `https://[username].github.io/IbPremiumArt/`
